# Завдання для Google Classroom

**Назва завдання:** Самостійна робота: Наскрізний проєкт «Cyber Tunnel Runner» — Етап 1: Перший контакт (10 балів)

---

### Опис завдання

Вітаємо на старті наскрізного курсового проєкту! У цій роботі ви починаєте розробку автопілота для швидкісного раннера в тунелі 3×3. 

> 💡 **Ідеологія Етапу 1:** Жодних жорстких обмежень щодо стилю коду. Ваша мета зараз — розібратися з моделлю гри та написати першу робочу логіку бота (можна навіть у звичному для вас стилі, «аби працювало!»). На наступних заняттях ми крок за кроком перепишемо це рішення у чисте функціональне ядро.

**Корисні матеріали:**
* Повний опис правил гри та фізики перешкод: `docs/n01_cyber_tunnel_runner.md`
* Код проєкту та шаблони ботів: папка `23_runner/`
* Автономний візуалізатор забігів у браузері: `docs/viewer/index.html`

---

### Критерії оцінювання Етапу 1 (Всього: 10 балів)

Усі зміни вносяться виключно у файли ботів (`23_runner/src/main/scala/runner/bots/ReflexBot.scala` або ваш власний клас бота). Рушій `Engine.scala` та генератор рівнів змінювати не потрібно.

#### 1. Старт і калібрування моторики (2 бали)
* Розібратися з моделлю даних (`Lane`, `Height`, `Action`, `Observation`).
* Захистити бота від невалідних рухів за межі тунелю: рух ліворуч дозволено лише для `Center` та `Right`, а рух праворуч — для `Left` та `Center`. Якщо маневр неможливий — бот обирає `KeepRunning`.
* **Перевірка:** запуск у чистому тунелі на 500 тіків без помилок:
  ```bash
  cd 23_runner
  sbt "run --bot=reflex --mode=sandbox --seed=2026 --ticks=500"
  ```

#### 2. Базова логіка виживання на смузі перешкод (5 балів)
* Замінити рандомний вибір дій у `ReflexBot.scala` на детермінований аналіз найближчого зрізу `observation.upcoming.head`:
  * **Висота 0 (`Low`)** ➔ стрибок (`Action.Jump`).
  * **Висота 1 (`Mid`)** ➔ присідання (`Action.Duck`) або стрибок (`Jump`).
  * **Висота 2 (`High`)** ➔ біг (`KeepRunning`) або присідання (`Duck`). **Стрибати суворо заборонено!**
  * **Комбо 0 + 2** або глуха стіна ➔ обов'язковий маневр на сусідню безпечну смугу (`MoveLeft` чи `MoveRight`).
* **Перевірка:** бот стабільно долає не менше **100–150 метрів** на смузі перешкод без зіткнень:
  ```bash
  sbt "run --bot=reflex --mode=obstacles --seed=2026 --ticks=200 --out=run_replay.json"
  ```

#### 3. Експорт та перевірка забігу у візуалізаторі (3 бали)
* Згенерувати файл запису забігу (`--out=run_replay.json`).
* Відкрити `docs/viewer/index.html` у браузері, завантажити `run_replay.json` та переконатися, що бот коректно реагує на перешкоди.
* Зафіксувати підсумкове табло термінала (`RunSummary`: подолана дистанція, статус).
